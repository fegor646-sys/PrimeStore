# PRIME STORE / PRIME COIN

Telegram Mini App: внутренняя валюта Prime Coin, магазин наград, достижения и админ-панель с CMS.
Стек тот же, что в RoyalMisteryBox: Node + Express + better-sqlite3 + ванильный фронтенд.

## Запуск

```bash
npm install
cp .env.example .env      # вписать BOT_TOKEN и ADMIN_IDS
npm start
```

Открыть в браузере без Telegram: раскомментировать `DEV_USER_ID` в `.env`. На проде переменную не задавать — иначе кто угодно сможет зайти под этим ID.

В @BotFather: **Bot Settings → Menu Button → Web App URL** → адрес деплоя.
Админ-панель: тот же адрес + `/admin.html` (доступ только для ID из `ADMIN_IDS`).

## Структура

```
app.js        HTTP-сервер и весь API
db.js         схема SQLite и бизнес-логика (баланс, покупки, акции)
telegram.js   проверка initData, уведомления админам и игрокам
catalog.js    стартовый ассортимент (только для первого запуска)
rewards.js    справочник начислений + настройки по умолчанию
public/       Mini App (index) и админ-панель (admin)
```

База — `db.sqlite` рядом с проектом, загруженные фото — в `public/uploads`. На Railway подключите volume на папку проекта, иначе и данные, и картинки потеряются при передеплое.

## Что уже реализовано

**Игрок.** Главный экран с балансом, двумя кнопками и всем ассортиментом без вкладок. Покупка Prime Coin (заявка админу). Экран «Заработать» со справочником комбинаций и турнирных достижений. Отправка заявки на достижение: 4 категории, скриншот, комментарий. Полная история операций. Заказы со статусами 🟡/🟢/🔴. Личный кабинет: баланс, заработано, потрачено, заказы, достижения, дата регистрации.

**Админ.** Заказы (выдать / отменить с возвратом монет). Достижения: видно игрока, Telegram ID, дату, категорию, скриншот, комментарий; при одобрении админ сам вводит сумму. Заявки на покупку Prime Coin. CMS товаров: создание, редактирование, цена, описание, порядок, скрытие, удаление, **загрузка фото прямо с телефона** (сжимается в браузере, файл кладётся в `public/uploads`, в базе хранится только путь; при замене и удалении старый файл подчищается). Акции: акционная цена + даты начала и окончания, цена возвращается сама. Управление способами заработка. Поиск игроков и ручное начисление (в том числе % от рейка и депозита). Настройки: проценты, курс, тексты.

## Как расширять

Всё, что в ТЗ помечено как «на будущее», добавляется без переписывания:

- **Новые товары** — через админку либо строкой в `catalog.js`.
- **Новые способы заработка, ежедневные задания, миссии** — раздел «Начисления» в админке: новая группа с любым названием сразу появляется на экране «Заработать».
- **Сезонные акции** — акционная цена с датами на любом товаре.
- **Промокоды, колесо удачи, уровни лояльности** — новая таблица в `db.js` и вызов `applyBalance(userId, amount, reason)`: баланс, история и профиль обновятся сами, потому что все движения монет идут через одну функцию.
- **Новые типы карточек** — поле `kind` у товара (`simple`, `variant`, `amount`, `slot`) плюс ветка в `purchase()` и в `openItem()`.

## Проверено

Загрузка фото товара с заменой и очисткой старого файла, автоначисление 5% (1000 грн рейка → 50 PC), покупка обычного товара, товара с номиналом и с количеством, списание и возврат при отмене, акционная цена в трёх состояниях (активна / запланирована / завершена), скрытие и возврат товара в продажу, заявка на достижение со скриншотом и одобрение с указанием суммы, заявка на покупку Prime Coin, создание товара через CMS.
