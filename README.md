# PRIME STORE / PRIME COIN

Telegram Mini App: внутрішня валюта Prime Coin, магазин нагород, досягнення та адмін-панель із CMS.
Стек той самий, що і в RoyalMisteryBox: Node + Express + better-sqlite3 + ванільний фронтенд.

## Запуск

```bash
npm install
cp .env.example .env      # вписати BOT_TOKEN і ADMIN_IDS
npm start
```

Відкрити в браузері без Telegram: розкоментувати `DEV_USER_ID` у `.env`. На проді змінну не задавати — інакше будь-хто зможе зайти під цим ID.

У @BotFather: **Bot Settings → Menu Button → Web App URL** → адреса деплою.
Адмін-панель: та сама адреса + `/admin.html` (доступ лише для ID зі списку `ADMIN_IDS`).

## Структура

```
app.js        HTTP-сервер і весь API
db.js         схема SQLite і бізнес-логіка (баланс, купівлі, акції)
telegram.js   перевірка initData, сповіщення адмінам і гравцям
catalog.js    стартовий асортимент (лише для першого запуску)
rewards.js    довідник нарахувань + налаштування за замовчуванням
public/       Mini App (index) і адмін-панель (admin)
```

База — `db.sqlite` поряд із проєктом, завантажені фото — у `public/uploads`. На Railway підключіть volume на папку проєкту, інакше і дані, і зображення загубляться при передеплої.

## Що вже реалізовано

**Гравець.** Головний екран із балансом, двома кнопками та всім асортиментом без вкладок. Купівля Prime Coin (заявка адміну). Екран «Отримати Prime Coin» із довідником комбінацій і турнірних досягнень. Надсилання заявки на досягнення: 4 категорії, скриншот, коментар. Повна історія операцій. Замовлення зі статусами 🟡/🟢/🔴. Особистий кабінет: баланс, зароблено, витрачено, замовлення, досягнення, дата реєстрації.

**Адмін.** Замовлення (видати / скасувати з поверненням монет). Досягнення: видно гравця, Telegram ID, дату, категорію, скриншот, коментар; при схваленні адмін сам вводить суму. Заявки на купівлю Prime Coin. CMS товарів: створення, редагування, ціна, опис, порядок, приховування, видалення, **завантаження фото просто з телефона** (стискається в браузері, файл кладеться в `public/uploads`, у базі зберігається лише шлях; при заміні та видаленні старий файл прибирається). Акції: акційна ціна + дати початку і завершення, ціна повертається сама. Керування способами заробітку. Пошук гравців і ручне нарахування (зокрема % від рейка та депозиту). Налаштування: відсотки, курс, тексти.

## Як розширювати

Усе, що в ТЗ позначено як «на майбутнє», додається без переписування:

- **Нові товари** — через адмінку або рядком у `catalog.js`.
- **Нові способи заробітку, щоденні завдання, місії** — розділ «Нарахування» в адмінці: нова група з будь-якою назвою одразу з'являється на екрані «Отримати Prime Coin».
- **Сезонні акції** — акційна ціна з датами на будь-якому товарі.
- **Промокоди, колесо фортуни, рівні лояльності** — нова таблиця в `db.js` і виклик `applyBalance(userId, amount, reason)`: баланс, історія та профіль оновляться самі, бо всі рухи монет ідуть через одну функцію.
- **Нові типи карток** — поле `kind` у товару (`simple`, `variant`, `amount`, `slot`) плюс гілка в `purchase()` і в `openItem()`.

## Перевірено

Завантаження фото товару із заміною та очищенням старого файла, автонарахування 5% (1000 грн рейка → 50 PC), купівля звичайного товару, товару з номіналом і з кількістю, списання та повернення при скасуванні, акційна ціна в трьох станах (активна / запланована / завершена), приховування та повернення товару в продаж, заявка на досягнення зі скриншотом і схвалення із зазначенням суми, заявка на купівлю Prime Coin, створення товару через CMS.
